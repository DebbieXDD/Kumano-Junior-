## 🌟 行程亮點速覽（兩方案共通）

*   ✈️ **羽田 ⇄ 南紀白濱（JAL 直飛 70 分鐘）**：省下 6 小時鐵路奔波，換得完整 4 天充實時間。
*   🚗 **白濱機場取還車（Fly & Drive）**：大行李全程放後車廂，免去山區每天付費託運行李。
*   🥾 **中邊路最精華 7km 緩下坡健行**：發心門王子 ➔ 水飲 ➔ 伏拜 ➔ 熊野本宮大社 ➔ 大齋原日本最大鳥居。
*   ⛩️ **朝聖名景**：神倉神社 538 階原始巨石階、大門坂 800 年古杉石疊參道、那智瀑布飛瀧神社。
*   🐟 **紀伊勝浦港**：品嚐全日本第一生鮮黑鮪魚延繩釣產地直送刺身與海鮮丼。
*   🐼 **白濱冒險世界（Adventure World）**：就在機場旁！近距離看大熊貓、野生動物園與海豚秀。
*   🌸 **在日居民專屬出發期**：精選 **4 月中旬（4/10～4/22）**，徹底避開 3 月柳杉花粉大爆發、零結冰、避開菜種梅雨與黃金週連假；或選 **2 月底**體驗季節限定的「川湯仙人風呂」！
